# Fiesta Ini Bot

## Dateien
- `main.py`
- `requirements.txt`
- `Procfile`
- `.gitignore`

## Railway Variable
Name: `DISCORD_TOKEN`  
Value: dein neuer Bot-Token

## Wichtig
Den Token niemals auf GitHub hochladen.

## Discord Developer Portal
Aktiviere:
- Server Members Intent

OAuth2 Scopes:
- bot
- applications.commands

Bot Permissions:
- View Channels
- Send Messages
- Embed Links
- Read Message History
- Use Slash Commands
