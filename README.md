- Abmelden mit gezielter Uhrzeit-Auswahl
- Bewerbungssystem 2.0
- Anonyme Ja/Nein-Abstimmungen mit min. 200 Zeichen Begründung
- Admin-Auswertung im Admin-Abstimmungschannel
